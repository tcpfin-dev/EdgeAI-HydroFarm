# EdgeAI-HydroFarm
Edge AI Device built with Nvidia Jetson Nano for Monitoring Farm activities

Title:  Developing an EdgeAI-HydroFarm

Deliverables:

1. Functional Hardware Prototype: A mockup farming tray equipped with an NVIDIA Jetson Orin Nano, an ESP32

microcontroller, a top-down camera, climate sensors, and working automated relays for lights and pumps.

2. Trained & Optimized AI Models: A custom-trained YOLOv8 object detection model weights file (best.pt)

alongside its compiled, high-performance NVIDIA TensorRT engine file (model.engine) optimized for the Jetson

architecture.

3. Source Code Repository: A complete GitHub repository containing the Python-based edge control logic

scripts, the Jetson.GPIO automation framework, and the Streamlit web dashboard source code.

4. Technical Documentation & Reports: A comprehensive final engineering report including a detailed System

Architecture Diagram, model training performance graphs (mAP, loss charts), hardware schematics, and an

operations user manual.
